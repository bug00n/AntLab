# AntLab

Двумерная симуляция муравьёв на Go и Ebitengine.

Запуск из корня проекта:

```sh
go run .
```

Настройки читаются из `config.json` при запуске:

```json
{
  "tps": 60,
  "world": {
    "width": 1000,
    "height": 700
  },
  "ant": {
    "count": 10
  }
}
```

`world.width` и `world.height` задают размеры мира и начального окна,
`ant.count` — число муравьёв. Все значения должны быть положительными целыми
числами. Муравьи появляются в центре мира.

`tps` задаёт число обновлений симуляции в секунду. Модель получает фиксированный
шаг времени `dt = 1 / tps`; скорость муравья задаётся в единицах мира в секунду
(сейчас 60). Вероятность случайного поворота также учитывает длительность шага.
Отрисовка использует VSync и синхронизируется с частотой монитора.

После изменения файла перезапусти приложение. Если файл отсутствует, содержит
некорректный JSON или недопустимые значения, приложение завершится с сообщением
об ошибке.
